# Safety Inspection Admin - Desktop App Version

This branch contains the Windows desktop application packaged with the pre-compiled installer:

- **Safety-Inspection-Admin-Desktop.zip** (~114 MB):
  - **Safety Inspection Admin Setup 1.0.0.exe**: Ready-to-use Windows installer. Just double-click to install.
  - Full desktop source code, assets, and Electron configurations (main.js, preload.js, package.json, server.js, public/, templates).

### Option 1: Install the Application
1. Download and extract **Safety-Inspection-Admin-Desktop.zip**.
2. Run **Safety Inspection Admin Setup 1.0.0.exe** to install on Windows.

### Option 2: Run / Rebuild from Source
1. In the extracted folder, run 
pm install.
2. Run 
pm start to run locally.
3. Run 
pm run build to package a new installer.
