# Safety Inspection Admin - Desktop App Version

This branch contains the desktop application packaged into a zip file:

- **Safety-Inspection-Admin-Desktop.zip**: Contains all desktop source files, assets, and Electron configurations (main.js, preload.js, package.json, server.js, public/, and templates).

### How to Run
1. Download and extract **Safety-Inspection-Admin-Desktop.zip**.
2. Run 
pm install inside the extracted folder.
3. Run 
pm start to launch the desktop app.
4. Run 
pm run build to compile the Windows .exe installer.
